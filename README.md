# 莲花土味表情包生成器

一个用于 Codex 的技能包：从内置的荷花、玫瑰、彩虹和闪耀背景中选择一款，生成带有重点文字的中文“长辈图”风格方形表情包。

## 功能

- 提供 4 款内置花卉背景供单选
- 支持用 `+` 标记需要重点突出的文字
- 生成 1:1 方形、色彩浓郁的中文表情包
- 重点文字使用红字、黄边和深色阴影，突出醒目

## 使用方法

在 Codex 中使用该技能后：

1. 选择背景：荷花蓝天、绿叶玫瑰、彩虹茶壶或荷花玫瑰晚霞。
2. 按以下格式发送文案：

   ```
   前文+重点文字+后文
   ```

例如：

```
我们什么时候+开组会+呢
```

其中“开组会”会作为画面中最大的重点文字。
