# 莲花土味表情包生成器 🪷

> 导师：文字我不看，有莲花我真回。

和导师沟通时，语言有时显得苍白无力；只有金光莲花，才能穿透老师的心灵。这个技能一键生成满级土味长辈表情包，让“老师您几点有空”进化成导师秒回秘籍。

年轻人和老年人，从此用同一种审美自如交流。

## Skill 介绍

这是一个专为“导师沟通困难户”准备的土味表情包生成器。它把认真想说的话，升级成红字黄边、金光四射、莲花与玫瑰齐飞的长辈风表情包。

## 使用方法

1. 先从四款背景中单选一张：荷花蓝天、绿叶玫瑰、彩虹茶壶或荷花玫瑰晚霞。
2. 输入你想说的话，并用两个 `+` 把重点词包起来。

例如：

```
我们什么时候+开组会+呢
```

Skill 会自动把“开组会”做成红色、黄边、巨大醒目的重点词；其他文字则是蓝色黄边，配上金光莲花、玫瑰和闪闪发亮的土味背景。

生成后直接保存、发送给导师即可。

## 适用场景

- 催导师回消息
- 问导师什么时间有空
- 约开会
- 问论文修改进度
- 求看 PPT
- 一切“文字不够有诚意”的沟通场景

毕竟，文字可能已读不回；但金光莲花，能让导师血脉觉醒。
